작업 제어 기능을 구현한다.

사용자가 명령어 끝에 앰퍼샌드(&)를 붙이면 해당 명령어를 백그라운드에서 실행한다. 백그라운드에서 실행된 작업은 작업 목록에 등록된다.

사용자에게 현재 실행 중이거나 중지된 작업들을 “jobs” 명령어를 통해 보여준다.

“fg %<job 번호>” 명령어를 통해 백그라운드 작업을 포그라운드로 전환한다.

“bg %<job 번호>” 명령어를 통해 중지된 작업을 백그라운드에서 재개한다.

“kill %<job 번호>” 명령어를 통해 특정 작업을 종료한다.

시그널 핸들러를 구현한다.

자식 프로세스의 종료, 중지, 재개 상태를 감지하기 위해 SIGCHLD 시그널 핸들러를 등록한다. 이 핸들러는 자식 프로세스의 상태 변화에 따라 작업 목록을 갱신하거나 작업을 제거한다.

Ctrl-C 입력 시 SIGINT 시그널이 포그라운드 작업에 전달되어 해당 작업을 종료한다.

Ctrl-Z 입력 시 SIGTSTP 시그널이 포그라운드 작업에 전달되어 해당 작업을 중지시키고, 작업 목록에서 상태를 “suspended”로 변경한다.

프로세스 그룹 및 터미널 제어를 수행한다.

백그라운드 작업은 별도의 프로세스 그룹으로 설정한다. 이를 통해 시그널이 포그라운드 작업에만 전달되도록 관리한다.

포그라운드 작업 실행 시 터미널 제어를 tcsetpgrp를 사용하여 자식 프로세스에 넘긴다. 작업이 종료되거나 중지되면 터미널 제어를 다시 셸로 복귀시킨다.
